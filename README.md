# SkinPort for GT New Horizons

SkinPort brings the Minecraft 1.8 skin format to Forge-based Minecraft 1.7.10. This fork is maintained primarily for the **GT New Horizons** modpack and its client stack, while remaining usable in other Forge 1.7.10 installations where compatible.
It may also be used outside of GT New Horizons, but compatibility with other modpacks or custom setups is not guaranteed.
