# SkinPort for GT New Horizons

SkinPort brings the Minecraft 1.8 skin format to Forge-based Minecraft 1.7.10. This fork is maintained primarily for the **GT New Horizons** modpack and its client stack, while remaining usable in other Forge 1.7.10 installations where compatible.

## Features

- Modern 64x64 player skins with hat, jacket, sleeve, and pants layers.
- Classic (Steve) and slim (Alex) player models, including correctly aligned slim armor.
- Skin and cape loading from Mojang, Crafatar, local files, or configurable custom servers.
- Legacy skin conversion and sensible Steve/Alex fallbacks.
- In-game controls for enabling or disabling individual skin layers.
- Rendering and resource-reload fixes for the GT New Horizons environment, including Angelica compatibility.

## Installation

Install Minecraft 1.7.10 with Forge, then place the release JAR in the `mods` directory. For GT New Horizons, use the version supplied by the modpack or download the latest build from [GitHub Releases](https://github.com/32east/SkinPort/releases/latest).
